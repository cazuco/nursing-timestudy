# ⏱ 業務タイムスタディ記録アプリ

看護業務の実施時間を「話すだけ・押すだけ」で記録し、AIが業務分類まで自動で行うWebアプリです。

## URL

このURLで試すことができます（スリープ状態のときは青色の起動ボタンを押してください）：
【(https://nursing-timestudy.streamlit.app/)】

利用にはGemini APIキーが必要です（[Google AI Studio](https://aistudio.google.com/apikey) で取得できます）。
※ ご自身のGemini APIキーをご用意ください（無料で取得できます）。

## 🌟 主な機能

- **音声で記録開始**: マイクを押して業務名を話し、止めた瞬間に計測が始まります。時刻の入力は不要です。
- **ワンタップで終了**: 「終了」を押すだけで、開始時刻・終了時刻・所要時間が自動で確定します。
- **AIによる業務分類**: 話した内容から、大分類（直接ケア／入退院関連／間接ケア）と中分類を自動で判定します。
- **個人情報の自動削除**: 患者名・職員名・部屋番号などの固有名詞をAIが削除してから記録します。
- **表記ゆれの統合**: 「体を拭く」「清拭」など、言い方が違っても同じ中分類にまとめます。
- **複数業務の分割**: 一度に複数の業務を話した場合、業務ごとに分けて記録し、所要時間を均等に割り振ります。
- **必要度タグの自動付与**: 中分類に応じて、看護必要度の関連区分をマスタ表から自動で付けます。
- **迷ったときの手動確定**: AIの確信度が低い場合は警告を表示し、大分類→中分類の2段階プルダウンで修正できます。
- **勤務条件の記録**: 勤務帯（日勤／夜勤／時短3区分）、ラダー、経験年数、受け持ち人数、役割（リーダー／スタッフ／フリー）を記録に付与します。
- **CSV出力とAI要約**: 記録をCSVでダウンロードできるほか、AIが業務量の傾向を要約します。

## 💡 オリジナリティ

**1. 看護師の操作を「押す・話す」だけに削った**

従来のタイムスタディは、紙に書くか、画面で業務項目を選ぶ方式が一般的です。手が塞がり、画面を見る余裕のない看護業務の実態には合っていません。本アプリは時刻の入力を排し、ボタンを押した時刻をアプリ側で取得する設計にしました。看護師が行うのは「マイクを押す・一言話す・終了を押す」だけです。

**2. 分類作業そのものをAIに肩代わりさせた**

自由な話し言葉から業務を特定し、分類体系に当てはめる処理をAIが担います。記録する人が分類を覚える必要がなく、表記ゆれも吸収されるため、記録者ごとの書き方の差が集計に影響しません。

**3. 個人情報を記録前に落とす設計**

発話には患者名や部屋番号が自然に混ざります。本アプリはAIが分類する段階で固有名詞を削除し、場所は区分（病室／ナースステーション／廊下／検査室／その他）に置き換えて記録します。記録に残る前に匿名化される構造です。

**4. 必要度タグはAIに判定させない**

看護必要度の区分は、AIの推測ではなくコード内のマスタ表から中分類に応じて機械的に付与します。判定のぶれをなくし、評価票の改定時は表の1か所を直すだけで済みます。

**5. 勤務形態の多様化を分析できる**

時短勤務を3区分で記録するため、勤務形態ごとに業務の中身がどう違うかを記録の段階から拾えます。

## 📝 使い方

1. 左のサイドバーにGemini APIキーを入力する
2. 記録者の条件（職員記号・勤務帯・ラダー・経験年数・受け持ち人数・役割）を選ぶ
3. 「音声で入力」タブでマイクを押し、これから行う業務を話して、もう一度押して止める
4. ケアを実施する
5. 「■ 終了」を押すと、AIが分類して確認画面が出る
6. 内容を確認して「✓ この内容で記録」を押す
7. 記録がたまったら「⬇ CSVでダウンロード」で保存する

## ⚠ 注意事項

- **記録はアプリ内に保存されません。** アプリを閉じる前に必ずCSVでダウンロードしてください。
- 本アプリは研修用の試作です。**患者情報や職員の実名は入力しないでください。** 職員は「看護師A」などの記号を使ってください。
- 入力内容（音声を含む）はGoogleのAIサービスに送信されます。
- 必要度タグは暫定です。実際の運用では最新の評価票で確認が必要です。

## 💻 使用技術

- **UI**: [Streamlit](https://streamlit.io/)
- **AI**: Google Gemini（`google-genai` / gemini-3-flash-preview）— 音声の聞き取り・匿名化・業務分類・傾向要約
- **データ処理**: [Pandas](https://pandas.pydata.org/)
